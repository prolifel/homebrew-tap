# Prolifel Tap

## How do I install these formulae?

`brew install prolifel/tap/<formula>`

Or `brew tap prolifel/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "prolifel/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
